# Deepfake Detective Academy — Technical Spec

Interactive museum demo (NEMO et al.) teaching audio-deepfake literacy to ages 8+.
Two AI personas: **Miko** (ASR, gullible listener) and **Agent Echo** (detective, spots fakes).
Five stations, 10–15 minutes, Dutch-first with English toggle.

## Deployment targets

Both run the *same* Next.js app; only the stats store differs.

- **Version A (museum / UvA server):** `docker compose up`. SQLite file volume. Kiosk mode.
- **Version B (personal Next.js site):** same app, `STATS_DRIVER=memory` or a hosted libSQL URL.
  If no DB is reachable the app still runs fully — stats degrade to "no data yet", never a crash.

Stations 2–5 are **pure static assets + one tiny API**. No GPU is needed at runtime.
All deepfake audio is **pre-generated offline** (see `tools/`).

## Data contract — `public/samples/manifest.json`

Generated by `tools/prepare_samples.py`. The app **must not** hardcode clip IDs; it reads this file.

There is exactly **one** description of this shape in the codebase:
`web/src/lib/manifest-schema.ts`. It has no `node:` imports, so the browser and the
API validate the pack with the same Zod schema. `web/src/components/manifest-types.ts`
only re-exports the types it infers — do not hand-write a second set.

Three states, three screens, never a 500:

| State | Browser | `GET /api/health` |
|---|---|---|
| No `manifest.json` | "run the sample pipeline" screen | `manifest.status: "failed"`, 503 |
| Present but invalid | same screen, plus the failing fields | `failed` + `problems[]`, 503 |
| Valid | the demo | `ok` |

Every asset path must be a site-absolute `/samples/…` URL with no `..` segment.
This is enforced by the schema, so a hand-edited manifest cannot point the kiosk at
another origin and the health check can map a path to a file on disk.

### Integrity rules the pipeline MUST enforce

1. **No format tell.** Every clip in `clips` — real and fake alike — is delivered as MP3 at the
   *same* bitrate, sample rate and channel count. A visitor must not be able to win by noticing
   that fakes "sound compressed". MLS and Voxtral outputs follow different source paths, so
   delivering them without uniform re-encoding would create a free giveaway.
2. **Loudness normalised** (EBU R128, `-16 LUFS`) so nobody guesses by volume.
3. **Trimmed to exactly 4.0 s** from a speech-active region so duration cannot reveal the label.
4. The ten cases interleave real/fake. Each difficulty 1–5 contains exactly one of each label,
   and the real and fake halves use disjoint `nl-XX` sentence IDs.
5. Every clip carries the actual Voxtral ASR transcript, mistakes included.

## HTTP API

All endpoints are anonymous. **No audio, no microphone data, no personal data is ever stored** —
only the aggregate counters below. That keeps the demo outside ethics-committee scope.

**The server is authoritative.** The client sends what the visitor *did*; it never
sends what that means. There is no `correct` field and no client-supplied `score`:
both are refused by the schema. The API resolves the clip's label from the validated
manifest, derives correctness, and derives the session score from the guesses it
accepted. An endpoint that believed `{"correct": true}` would have no numbers worth
reporting the moment it was reachable from the open internet.

Bounds, so the one write endpoint stays finite: request bodies are capped at
**2 KiB** (checked by declared length and while streaming raw bytes), `clipId` at 128
characters, and every unknown field is rejected outright.

Throttling is keyed on the anonymous `sessionId` from the body — **never on an IP
address, hashed or otherwise** — plus one global bucket. 60 events per session per
minute and 1 200 overall; over that, `429` with `Retry-After`. All of it is
in-process and expires within one window.

### `POST /api/events`

```jsonc
// request — one of:
{ "sessionId": "uuid-v4, minted in memory, dropped on reset",
  "station": 2,                          // 1..5
  "lang": "nl",                          // "nl" | "en"
  "type": "guess", "clipId": "case-03", "guess": "fake" }

{ "sessionId": "…", "station": 3, "lang": "nl",
  "type": "station_enter" }              // also: station_complete | station_skip
                                         //       session_complete | session_reset

{ "sessionId": "…", "station": 5, "lang": "nl",
  "type": "final_scenario", "choice": "callback" }  // send | reply | callback | unsure
```

```jsonc
// response 200 — or 202 with the same body when the stats driver is unavailable
{ "accepted": true,       // false for a repeat guess: answered, not counted
  "persisted": true,      // false when the stats driver is down
  "guess":    { "clipId": "case-03", "guess": "fake", "label": "fake", "correct": true } | null,
  "scenario": { "choice": "callback", "correct": true } | null,
  "session":  { "answered": 3, "correct": 2 },   // derived from accepted guesses
  "clipStats":{ "clipId": "case-03", "guesses": 214, "fooledPct": 71 } | null }
```

The reveal reads `guess` and `clipStats` straight off this response. It must not
POST the guess and then GET the clip's stats — that is a read-after-write race
against its own write, and the "71% were fooled" line could exclude the visitor
standing in front of it.

Errors: `400 invalid_event` / `invalid_json`, `404 unknown_clip` (a clip id the
manifest does not contain is refused, never counted), `413 body_too_large`,
`429 rate_limited`. Never 5xx.

### `GET /api/stats/clip/:clipId`
Still available for direct links and tooling; Station 2 no longer needs it.

```jsonc
{ "clipId": "case-03", "guesses": 214, "fooledPct": 71 }
// fooledPct = share of guesses that were WRONG. Below 10 guesses it is null, so the
// UI hides the stat instead of showing a noisy 100%.
// 404 unknown_clip for an id the manifest does not contain.
// 202 with the same shape when the stats driver is unavailable.
```

### `GET /api/stats/summary`
Drives Station 5's closing screen.

```jsonc
{ "sessionsToday": 214, "avgScore": 3.1,
  "hardestClip": { "clipId": "case-05", "fooledPct": 78 } | null,
  "verifyFirstPct": 62 | null }   // share who chose to call back and check
```

Returns `202` with the same shape when the stats driver is unavailable; the
closing screen treats that as a supported no-crowd-data state.

### `GET /api/health`
For whoever gets the kiosk running before the doors open. It answers the three
things that actually go wrong on the morning of an exhibition, and says nothing
about internals — no file-system paths, no stack traces, no environment.

```jsonc
{ "status": "ok",                 // "ok" | "degraded" | "failed"
  "checks": {
    "app":      { "status": "ok" },
    "manifest": { "status": "ok", "present": true, "valid": true,
                  "clips": 22, "codecRungs": 4, "factoryClips": 16,
                  "languages": ["en", "nl"],
                  "problems": ["clips.0.label: …"] },   // only when invalid
    "media":    { "status": "ok", "checked": 12, "missing": 0, "examples": [] },
    "stats":    { "status": "ok", "driver": "sqlite", "available": true } } }
```

`200` when the exhibit can run, `503` only when it cannot. Stats being down is
`degraded`, not `failed` — it costs the reporting, never the teaching. `media`
spot-checks a spread of the manifest's assets rather than stat-ing all ~120.

## SQLite schema

```sql
CREATE TABLE IF NOT EXISTS events (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  ts         TEXT    NOT NULL DEFAULT (datetime('now')),
  session_id TEXT    NOT NULL,
  station    INTEGER NOT NULL,
  type       TEXT    NOT NULL,
  clip_id    TEXT,
  guess      TEXT,
  correct    INTEGER,   -- 0/1/NULL, derived server-side
  score      INTEGER,   -- derived server-side, only on session_complete
  choice     TEXT,      -- final-scenario answer
  lang       TEXT    NOT NULL DEFAULT 'nl'
);
CREATE INDEX IF NOT EXISTS idx_events_clip ON events(clip_id) WHERE clip_id IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_events_ts   ON events(ts);
-- Best-effort: skipped with a warning on an existing database that already
-- contains duplicate guesses. De-duplication also happens in process.
CREATE UNIQUE INDEX IF NOT EXISTS idx_events_guess_once
  ON events(session_id, clip_id) WHERE type = 'guess';
```

`session_id` is a random UUID-v4 minted in memory and used only to de-duplicate a
visitor's own guesses and to derive their score. It is not a cookie, is not
correlated across sessions, and a reset drops it on both sides. There is exactly one
generator (`web/src/lib/uuid.ts`), with a `getRandomValues` and a `Math.random`
fallback for browsers without `crypto.randomUUID` — a non-conforming id is rejected
by the API, so a kiosk browser without it would otherwise report nothing at all.

**Bounded retention.** Both stores are finite by construction, so a kiosk left
running unattended for a year cannot grow without limit:

| Knob | Default | Env |
|---|---|---|
| Age cutoff (SQLite) | 90 days | `STATS_RETENTION_DAYS` |
| Row cap (SQLite) | 500 000 | `STATS_MAX_ROWS` |
| Event cap (memory driver) | 50 000 | `STATS_MAX_MEMORY_EVENTS` |
| Live sessions held in memory | 2 000, 2 h TTL | — |

Pruning runs at most every 30 minutes, on write.

## i18n

Single `web/src/i18n/{nl,en}.json`. Dutch is the default, English the fallback, the
key itself the floor. Every user-visible string is a key — no hardcoded copy in
components. The toggle persists in `localStorage` only, and also sets
`document.documentElement.lang`, so a screen reader switches voice with the copy.
The translator lives in `web/src/lib/i18n-core.ts`; both dictionaries must carry the
same keys and the same `{placeholders}` (enforced by `tests/i18n.test.ts`).

## Kiosk behaviour

- A **sound check** precedes station 1: one real clip from the pack, played on an
  explicit tap (never autoplay), one "can you hear it?", and troubleshooting plus a
  way past for anyone who cannot. Every station after it is audio.
- 90 s idle → attract-mode screen; 45 s idle on Station 5 → full reset to Station 1.
  Both live in `web/src/lib/kiosk-flow.ts`, which is the only place transitions happen.
- Every station has a skip (`→`) affordance so an abandoned session never blocks the
  next visitor. Skips are reported as `station_skip`, so an exhibit where 40% of
  visitors skip Station 3 is a finding rather than a gap.
- Progress rail of 5 segments, always visible, with a spoken equivalent.
- The demo ends on a **scenario**, not a score: a voice you know asks for money, and
  the correct action is to hang up and call back on a number you already have. It is
  the only part that transfers outside the room, so it is the last thing a visitor
  does and the first tip on the diploma.

## Honesty rules

The demo is about deception, so it must not practise any:

1. **Clues are clues.** Spectrogram tells are framed as evidence about *these
   clips*, never as a test that works on the next voice message. Modern fakes add
   breath and room noise; plenty of genuine recordings sound spotless. Copy that
   states a clue as a certainty fails `tests/i18n.test.ts`.
2. **Echo is theatre, and says so.** Agent Echo knows which clips are fake because
   the pack ships with prepared labels — nothing on the screen analyses audio. Both
   Station 2 and Station 4 disclose this in the visitor's own language.
3. **Nothing is invented.** Transcripts are the ASR's real output, mistakes
   included; Station 1's "loudest moment" is measured from the decoded audio in the
   browser; Station 3's verdict is read off the pack's own transcripts. If a future
   pack degrades differently, the station teaches whatever that pack shows.

## Accessibility

- Zoom is not blocked (`userScalable: true`, `maximumScale: 5`).
- The whole flow fits a 320 px viewport with no horizontal scroll.
- Verdicts, playback failures, stage changes and timed reveals are announced
  through one pair of live regions (`components/kiosk/announcer.tsx`). The
  typewriter exposes its finished line once, not one character at a time.
- The scrubbable spectrogram is a real `role="slider"`: arrow keys, Home, End, and
  a described hint.
- After a guess is committed, the clue is also given as text, so someone who cannot
  see the highlighted box or hear the clip gets the same evidence. Never before.
- `prefers-reduced-motion` collapses the staging, never the content: `useBeat`
  reveals every beat at once and the typewriter prints its line whole.

## Design system

Identity: **a forensic lab, after hours.** Colour is semantic, never decorative:

| Token | Meaning |
|---|---|
| `miko-*` (amber) | Miko, the listener. Warm, eager, naive. |
| `echo-*` (teal) | Agent Echo, the analyst. Cool, sceptical. |
| `real-*` / `fake-*` (green/red) | Verdicts only. Never used for chrome. |
| `ink-*` (near-black navy) | Surfaces. Deliberately desaturated so the spectrogram's magma palette is the brightest thing on screen. |

- **The personas are SVG, not emoji** (`components/kiosk/Personas.tsx`). Emoji rendered
  differently on every OS and could not react. The shape language *is* the lesson: Miko is a soft
  circle (open, trusting), Echo is a hard shield (guarded, suspicious) — a child reads the
  difference from the silhouette before reading a word of Dutch. They have moods
  (`listening` / `happy` / `alert`): Miko's eyes widen when he hears, Echo's lens flares red on a catch.
- **Type**: Bricolage Grotesque (display) / Nunito (body, comfortable for an 8-year-old) /
  JetBrains Mono (case numbers, evidence labels). All ticking numbers use `.tnum`.
- **Motion is functional, never decorative.** Entrances are split and staggered (`.rise` + delay);
  the verdict `.stamp` lands once and hard; `.scan` sweeps the spectrogram while Echo analyses;
  `.clue` pulses the evidence border. Everything honours `prefers-reduced-motion`.
- **The spectrogram is the hero.** Framed like something under glass, with a spotlight (a
  `0 0 0 9999px` shadow) that dims everything *except* the clue — a plain outline gets lost in a busy
  spectrogram.
- Concentric radii throughout (`outer = inner + padding`), press feedback at `scale(0.96)`, layered
  shadows rather than hard borders, and ≥40px hit areas on every control.
