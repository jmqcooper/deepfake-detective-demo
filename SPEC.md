# Deepfake Detective Academy — Technical Spec

Interactive museum demo (NEMO et al.) teaching audio-deepfake literacy to ages 8+.
Two AI personas: **Miko** (ASR, gullible listener) and **Agent Echo** (detective, spots fakes).
Five stations, 10–15 minutes, Dutch-first with English toggle.

## Deployment targets

Both run the *same* Next.js app; only the stats store differs.

- **Version A (museum / UvA server):** `docker compose up`. SQLite file volume. Kiosk mode.
- **Version B (personal Next.js site):** same app, `STATS_DRIVER=memory` or a hosted libSQL URL.
  If no DB is reachable the app still runs fully — stats degrade to "no data yet", never a crash.

Stations 2–5 are **pure static assets + one tiny API**. No GPU is needed at runtime.
All deepfake audio is **pre-generated offline** (see `tools/`).

### Integrity rules the pipeline MUST enforce

1. **No format tell.** Every clip in `clips` — real and fake alike — is delivered as MP3 at the
   *same* bitrate, sample rate and channel count. A visitor must not be able to win by noticing
   that fakes "sound compressed". MLS and Voxtral outputs follow different source paths, so
   delivering them without uniform re-encoding would create a free giveaway.
2. **Loudness normalised** (EBU R128, `-16 LUFS`) so nobody guesses by volume.
3. **Trimmed to exactly 4.0 s** from a speech-active region so duration cannot reveal the label.
4. The ten cases interleave real/fake. Each difficulty 1–5 contains exactly one of each label,
   and the real and fake halves use disjoint `nl-XX` sentence IDs.
5. Every clip carries the actual Voxtral ASR transcript, mistakes included.

## HTTP API

All endpoints are anonymous. **No audio, no microphone data, no personal data is ever stored** —
only the aggregate counters below. That keeps the demo outside ethics-committee scope.

### `POST /api/events`
Fire-and-forget. Client must never block the UI on this call, and must ignore failures.

```jsonc
// request
{ "sessionId": "uuid-v4 generated client-side, not persisted anywhere else",
  "station": 2,                // 1..5
  "type": "guess",             // "station_enter" | "guess" | "station_complete" | "session_complete"
  "clipId": "case-03",         // optional
  "guess": "fake",             // optional: "real" | "fake"
  "correct": true,             // optional
  "score": 4,                  // optional, only on session_complete
  "lang": "nl" }
// response: 204 No Content   (or 202 if the stats driver is unavailable — never 5xx)
```

### `GET /api/stats/clip/:clipId`
Drives the "71% of visitors were fooled by this one!" reveal.

```jsonc
{ "clipId": "case-03", "guesses": 214, "fooledPct": 71 }
// fooledPct = share of guesses that were WRONG. If guesses < 10, return "fooledPct": null
// so the UI can hide the stat instead of showing a noisy 100%.
```

### `GET /api/stats/summary`
Drives Station 5's leaderboard screen.

```jsonc
{ "sessionsToday": 214, "avgScore": 3.1,
  "hardestClip": { "clipId": "case-05", "fooledPct": 78 } | null }
```

## SQLite schema

```sql
CREATE TABLE IF NOT EXISTS events (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  ts         TEXT    NOT NULL DEFAULT (datetime('now')),
  session_id TEXT    NOT NULL,
  station    INTEGER NOT NULL,
  type       TEXT    NOT NULL,
  clip_id    TEXT,
  guess      TEXT,
  correct    INTEGER,   -- 0/1/NULL
  score      INTEGER,
  lang       TEXT    NOT NULL DEFAULT 'nl'
);
CREATE INDEX IF NOT EXISTS idx_events_clip ON events(clip_id) WHERE clip_id IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_events_ts   ON events(ts);
```

`session_id` is a random client-side UUID used only to de-duplicate a visitor's own guesses.
It is not a cookie, is not correlated across sessions, and is dropped on reset.

## i18n

Single `web/src/i18n/{nl,en}.json`. Dutch is the default. Every user-visible string is a key —
no hardcoded copy in components. Language toggle persists in `localStorage` only.

## Kiosk behaviour

- 90 s idle → attract-mode screen; 45 s idle on Station 5 → full reset to Station 1.
- Every station has a skip (`→`) affordance so an abandoned session never blocks the next visitor.
- Progress rail of 5 segments, always visible.

## Design system

Identity: **a forensic lab, after hours.** Colour is semantic, never decorative:

| Token | Meaning |
|---|---|
| `miko-*` (amber) | Miko, the listener. Warm, eager, naive. |
| `echo-*` (teal) | Agent Echo, the analyst. Cool, sceptical. |
| `real-*` / `fake-*` (green/red) | Verdicts only. Never used for chrome. |
| `ink-*` (near-black navy) | Surfaces. Deliberately desaturated so the spectrogram's magma palette is the brightest thing on screen. |

- **The personas are SVG, not emoji** (`components/kiosk/Personas.tsx`). Emoji rendered
  differently on every OS and could not react. The shape language *is* the lesson: Miko is a soft
  circle (open, trusting), Echo is a hard shield (guarded, suspicious) — a child reads the
  difference from the silhouette before reading a word of Dutch. They have moods
  (`listening` / `happy` / `alert`): Miko's eyes widen when he hears, Echo's lens flares red on a catch.
- **Type**: Bricolage Grotesque (display) / Nunito (body, comfortable for an 8-year-old) /
  JetBrains Mono (case numbers, evidence labels). All ticking numbers use `.tnum`.
- **Motion is functional, never decorative.** Entrances are split and staggered (`.rise` + delay);
  the verdict `.stamp` lands once and hard; `.scan` sweeps the spectrogram while Echo analyses;
  `.clue` pulses the evidence border. Everything honours `prefers-reduced-motion`.
- **The spectrogram is the hero.** Framed like something under glass, with a spotlight (a
  `0 0 0 9999px` shadow) that dims everything *except* the clue — a plain outline gets lost in a busy
  spectrogram.
- Concentric radii throughout (`outer = inner + padding`), press feedback at `scale(0.96)`, layered
  shadows rather than hard borders, and ≥40px hit areas on every control.
